# Restaurant Simulation

В данном проекте реализован симулятор работы ресторана. Проект включает в себя несколько компонентов:

1. **Моделирование работы поваров и клиентов**:
    - Класс Order представляет заказ.
    - Класс CustomerGenerator генерирует случайные заказы.
    - Класс Cook обрабатывает заказы.

2. **Симуляция работы ресторана**:
    - Ограниченная очередь для заказов (BlockingQueue<Order>).
    - Пул потоков для поваров (ExecutorService).

3. **Метрики и отчетность**:
    - Счетчик уникальных ID заказов (AtomicInteger orderIdGenerator).
    - Счетчик успешно приготовленных блюд (AtomicInteger totalServed).

4. **Запуск симуляции**:
    - Основной метод main запускает симуляцию, включая генерацию заказов и обработку их поварами.
    - Симуляция продолжается 10 секунд.
